# 青梧大学 · 大学生存图鉴

一款以校园大世界探索为核心的剧情成长游戏。当前版本包含原生微信小程序与零依赖浏览器预览，两端共用角色、剧情、成长、考试和地图引擎。

## 已实现

- 4 名可选角色，独立初始属性、四种发型设定、人物配色与角色特长（发丝/衣领/高光等细节绘制）
- 人物四向建模：正/背/左/右分别有独立画法（背面是后脑与背包，侧面是单眼、鼻梁与下颌线）
- 2400 × 1600 校园地图，人物行走、点击寻路、建筑碰撞与镜头跟随
- 图书馆、教学楼、实验楼、食堂、宿舍、体育馆、社团中心、青梧湖共 8 大场景
- 每个场景配有专属插画风背景：星空、月亮、书架、黑板、烧瓶气泡、食堂蒸汽、寝室串灯、体育馆跳球、舞台聚光灯、湖畔萤火虫
- 每个场景 2 个可接对话任务，共 16 段原创故事、多选项对话与重复体验收益递减
- 学识、体魄、心态、人缘、实践、精力 6 项状态
- 8 个学期覆盖完整大学四年：每学期 4 周行动 + 1 次期末考，假期恢复精力
- 期末考 5 道情境题（10 题题库，由本局种子码抽取）+ 日常成长计分，学期结算面板
- 随机种子：每局生成 6 位种子码，同一角色 + 同一种子码可复现完全相同的一段四年
- 选择日志：随时翻看做过的选择、所在学期周次与属性变化，关掉后回到打开日志前的地方
- 大四下学期结束后按四年积累进入毕业结局：学术深造、学生领袖、创新实践、温暖人生、未来可期
- GitHub Actions 自动运行核心逻辑、语法与构建检查

## 快速体验

### 浏览器

直接打开 `web/index.html`，或在项目目录运行：

```bash
npm start
```

访问 `http://127.0.0.1:8080`。电脑使用 WASD / 方向键移动、E 互动，也可点击地图寻路；手机使用虚拟摇杆。

### 微信开发者工具

1. 打开微信开发者工具，选择「导入项目」。
2. 目录选择本项目根目录（包含 `project.config.json`）。
3. 测试阶段可使用测试号；正式发布时在 `project.config.json` 替换为团队小程序 AppID。
4. 编译后从角色页进入校园。

## 目录约定

```text
miniprogram/
  data/content.js          # 角色、建筑、NPC、场景美术、16 段任务剧情、题库与结局内容
  engine/core.js           # 属性、学期周数、按种子抽题、期末考试和毕业结局逻辑
  engine/random.js         # 种子码编解码与可复现随机数（熵由界面传入，引擎自己不掷骰子）
  engine/choicelog.js      # 选择日志视图模型（两端共用）
  engine/renderer.js       # Canvas 校园、人物与场景插画背景绘制
  engine/world.js          # 移动、碰撞、镜头交互所需的世界状态
  pages/select/            # 角色选择页
  pages/game/              # 小程序游戏页与交互
web/                       # 浏览器预览；bundle.js 为自动生成文件
web/sprite-lab.html         # 人物建模对照页（4 角色 × 4 朝向 × 站立/走路）
scripts/                   # 构建、静态服务器与检查脚本
tests/core.test.js         # 核心玩法回归测试（含八学期全流程）
.github/workflows/ci.yml   # 团队自动检查
```

## 组员协作

建议按模块分工，减少冲突：

- 剧情同学只改 `miniprogram/data/content.js`。
- 地图与美术同学主要改 `engine/renderer.js`，人物绘制说明见 `角色建模说明.md`，改完打开 `web/sprite-lab.html` 对照。
- 玩法同学改 `engine/core.js` 与 `tests/core.test.js`。
- 小程序交互同学改 `pages/`，浏览器交互同学改 `web/app.js` 与 `web/styles.css`。

每次修改共享引擎或内容后，提交前运行：

```bash
npm test
npm run check
npm run build
```

`web/bundle.js` 由构建脚本生成，不要直接编辑。小程序本身不需要 npm 依赖。

## 首次上传到 GitHub

由仓库负责人在 GitHub 新建空仓库（不要自动生成 README），然后在本目录执行：

```bash
git init
git add .
git commit -m "feat: 青梧大学校园大世界首个可玩版本"
git branch -M main
git remote add origin <团队仓库地址>
git push -u origin main
```

组员随后克隆仓库，基于 `main` 新建功能分支并提交 Pull Request。不要多人直接同时推送到 `main`。
